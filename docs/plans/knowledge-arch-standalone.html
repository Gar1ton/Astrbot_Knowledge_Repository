桌面壳用什么技术？

Tauri 与 Electron 的窗口内仍用 Web 技术绘制界面。但没有浏览器，没有对外端口，也没有登录页。
Phase 4 变成一个全新的 Qt 前端。工作量是其他选项的数倍。

Tauri 壳启动 Python 后端，只把端口和 token 交给自己的窗口。

新 KA 仓库的 Git 历史从哪里开始？

两种方式都只在本地操作。推送到 Gar1ton/Knowledge-Arch 时用新分支。替换 main 需要你单独批准。

不改：检索算法、数据 schema、同步语义。

  • 检索、chunking、清洗、六档检索模式、引用格式保持原样。
  • migrations/ 的 SQL 文件不改。旧库导入后直接可用。
  • Zotero、Notion、R2 的同步语义不变。只换接入方式和设置位置。
  • 不读取 AstrBot 自己的模型密钥。首次启动由用户在「模型供应商」里填写。
  • 不做局域网或远程访问的 Web 控制台。不做 API 型 rerank。
  • Astrbot_KAPlugin 仓库保持原样，不删除，不归档。
  • 不参考 Gar1ton/Knowledge-Arch 旧实现的代码。
  • header 里的文件数是估算值。
